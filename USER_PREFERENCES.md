# Переваги співпраці

Користувач просить постійно рекомендувати зміну моделі, коли це справді доречно
для конкретного завдання. Поточну модель описує як «Soul легка»; точну назву
та рівень міркування не вважати підтвердженими без даних інтерфейсу.

Перед складною архітектурою, діагностикою або значними змінами коду оцінити,
чи потрібна зміна моделі або рівня міркування. Якщо потрібна — коротко назвати
конкретну доступну модель, рівень і причину. Для простих дій не повторювати
рекомендації. Самостійно модель не перемикати. Враховувати актуальний перелік
моделей, а не застарілі назви. Ця перевага стосується роботи над цим проєктом.
