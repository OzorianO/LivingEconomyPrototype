## Обмеження, які впливають на план

- Сценарій обмежений однією фермою та однією пекарнею.
- NPC проходять спільні фази дня; індивідуальних планів та сну як потреби немає.
- Швидкий режим обертає чергу покупців, 3D спирається на порядок прибуття.
- Рух використовує MoveTowards; обходу перешкод через NavMesh немає.
- Праця та виробництво відбуваються спрощено при прибутті, без тривалості роботи.
- Один слот Save/Load зберігає лише завершений день.
- Гравець зараз спостерігає та використовує тестові кнопки. Остаточна роль не визначена.

після M1–M4, по одному фактору з перевіркою наслідків.
