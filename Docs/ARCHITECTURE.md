# Архітектура — план

```text
My Game/
  Docs/
  Simulation/                  незалежна C#-бібліотека і перевірки
  LivingEconomyPrototype/      створюється через Unity Hub
    Assets/_Project/
      Scenes/
      Scripts/Simulation/     код ядра без UnityEngine
      Scripts/Presentation/   Unity-компоненти, UI і відображення
      Scripts/Editor/         інструменти редактора
      Data/                   товари, професії, стартовий сценарій
      Prefabs/
      Materials/
      UI/
      Art/
      Audio/
```

Фактичні папки коду створюємо під час реалізації. Єдине джерело C# ядра —
Scripts/Simulation: окремий .NET-проєкт підключає ті самі файли, не їхні копії.
Цільову версію C#/.NET і пакети фіксуємо після перевірки встановленого Unity.

Модулі ядра: годинник із фіксованим кроком, NPC, рахунки, інвентарі,
рецепти, підприємства, працевлаштування, ринок, журнал, звіти.
NPC та професії описуються даними зі стабільними ID; баланс відділено від правил.
Випадковість використовує заданий seed; порядок обробки стабільний.

Unity читає стан симуляції та передає команди. Transform, фізика і кадри
не визначають бухгалтерські правила. Збереження згодом містить версію схеми,
час, стан генератора випадковості, рахунки, запаси, NPC та підприємства.
