# LivingEconomyPrototype

Unity 6.6 (`6000.6.1f1`), Universal 3D. Проєкт: `D:\UnityProjects\LivingEconomyPrototype`.

## Запуск

Відкрити `Assets/_Project/Scenes/MainSimulation.unity` і натиснути Play.
З’явиться панель 20 NPC: гаманець, професія, зерно, хліб і поле голоду.
Кнопки демонструють покупку хліба, переказ наявних грошей та скидання сценарію.
Стартові кошти і товари, успішні операції та відмови записуються в журнал.
Стан є тимчасовим: вихід із Play Mode або Reset створює сценарій заново.

## Поточний етап

Готові особисті гаманці, інвентарі, атомарні покупки, перекази, журнал
і відтворюваний стартовий сценарій (seed 42). Ядро не залежить від Unity API.
Голод поки лише поле стану. Автоматичних днів, виробництва, найму, бізнес-рахунків,
споживання, збережень і руху NPC ще немає. Ручний переказ не є системою зарплат.
Наступний етап: час, виробництво, споживання та фінансований найм.

## Перевірки

```powershell
dotnet run --project Simulation/Checks/Checks.csproj
```

Перевірки компілюють ті самі файли ядра, що використовує Unity, без сторонніх пакетів.
18.09.2026: PASS, 38 тверджень і 10 000 кроків змішаних операцій.
Перевірено успішні угоди, відмови без часткових змін, переповнення,
невідомі ID/товари, журнал, відтворюваність сценарію і збереження грошей.
Це перевірки бухгалтерії; виживання поселення ще не перевіряється.
Unity успішно скомпілював ядро; у Play Mode перевірено покупку й оплату.

Початкові дизайн-документи у `Docs` описують план, а не повністю реалізовану гру.
